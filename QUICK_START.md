## Troubleshooting

❌ **"Couldn't connect to server"**
- Make sure your phone and computer are on the **same WiFi**
- Try entering the URL again
- Check that the Expo server is still running

❌ **"Network error"**
- Disable VPN on your phone
- Check firewall isn't blocking port 8081

❌ **App crashes on load**
- Make sure you're running the latest Expo Go version
- Try restarting the Expo server:
  ```bash
  npm start
  ```
